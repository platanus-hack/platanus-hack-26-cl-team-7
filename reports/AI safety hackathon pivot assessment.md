# AI safety hackathon pivot assessment

21 November 2026 · Decision memo for the Último Paso team

## Executive summary

**Build one experiment on cross-session monitoring with hidden grouping.** Ask whether independently recorded changes to shared state help a monitor find the relevant earlier sessions in time to catch a policy violation, under the same review budget as a per-session monitor. The closest studies already show that joint review can work when the relevant group is supplied and that persistent monitor notes help within one repository. The weekend contribution would be the measured value of **retrieving the right evidence from an interleaved stream**, with the group withheld and with a strong transparent baseline. A useful negative result would show where trusted history adds little or fails when records are incomplete. [Makins et al., FakeLab](https://arxiv.org/html/2607.07368#S4) · [Hills et al., Persistent-State AI Control](https://arxiv.org/html/2607.02514#S4) · [Red-Teaming Multi-Agent Attacks](https://arxiv.org/html/2610.24052)

**Keep the evidence infrastructure. Cut the WAF feature roadmap from the entry.** The prototype's fixture run reduced client-visible evidence from 6/9 direct trials to 1/9 proxied trials. Five reattempts were contained, and legitimate tasks succeeded 9/9 in each arm. In the separate Langflow experiment, in-band disclosure stopped while backend execution continued. Both are defensible engineering results, but neither identifies an advantage in monitoring an AI agent's behavior across sessions. Cloudflare already markets request–response exploit confirmation and response blocking. If the cross-session pilot lacks headroom, pivot to **calibration transfer in native Spanish banking**. The repository already contains evidence of a utility failure in that setting. [Fixture results](../ultimo-paso/scoreboard/evidence/PIPELINE.md) · [Langflow results](../ultimo-paso/README.md#results) · [Cloudflare full transaction detection](https://blog.cloudflare.com/full-transaction-waf/) · [Team banking pilot](../vault/resultados.md)

The Spanish study referenced in the brief was not accessible as a separate attachment in this workspace. This memo uses the supplied description as context, the repository's recorded results for team-specific claims, and primary public sources for the prior-art assessment.

[FakeLab](https://arxiv.org/html/2607.07368#S4) · [October follow-up](https://arxiv.org/html/2610.24052) |

## Ranked weekend experiments

### 1. Can trusted state history recover related sessions before a monitor runs out of budget?

**Setting and technique.** Use three separated sessions in a simulated approval workflow. The service emits its own versioned receipts for ordinary actions. Interleave independent workflows that reuse actors or touch similar objects. Hide incident labels, preassembled groups, and any identifying synthetic markers from the monitor. Test a bounded retrieval policy that follows typed dependencies in the receipts and presents two short prior excerpts with the current session. Keep the receipt producer outside agent control. The labels come from an independent policy and final-state check. “Related” means materially connected to the same policy outcome, with no inference about who an agent is or whether it intended harm.

**Baseline and headline metric.** Measure **incident recall before the simulated policy deadline at a fixed budget**, initially ten reviews per 100 sessions on the frozen evaluation mix. Hold reviewer, token cap, review timing, and eligibility fixed. Compare current-session-only review, recency retrieval from the same receipt pool, and a deterministic state-policy check. Add oracle grouping as a diagnostic upper bound and shuffle the selected histories to verify that any improvement comes from relevance. Report benign alerts per 100 sessions and show the raw denominators. If alerted episodes cluster within one incident, uncertainty is computed at the incident or scenario-family level. FinHarness's retrieval baseline belongs in the comparison when its within-trajectory selectors can be adapted without giving it the hidden group labels.

**Demo and kill criterion.** Show one valid-looking session that becomes interpretable when the right earlier receipt appears, then a busy benign session the monitor declines to group. By the first checkpoint, oracle grouping must beat the baseline on disjoint pilot scenarios to establish headroom. If a simple state check captures all meaningful positives, use that as the result and move the hackathon build to #2. Bound the claim to retrieval across separate sessions under realistic interference; joint review of known agent groups and within-session memory already have direct precedents. [FakeLab](https://arxiv.org/html/2607.07368#S4) · [Link-tracker](https://arxiv.org/html/2607.02514#S4.SS3) · [FinHarness memory](https://arxiv.org/html/2605.27333#S3.SS4) · [Joint-monitor follow-up](https://arxiv.org/html/2610.24052#S4.SS2)

### 2. Does calibration on native Spanish preserve more authorized banking tasks at the same review budget?

**Setting and technique.** Use fictional AgentDojo banking decisions with a sandbox ledger and native-reviewed Chilean Spanish, neutral Spanish, and English versions of the same task. Preserve the intended operation and ledger state across each matched set. Cross language with source and format so prose, structured service output, and independently authorized requests can be distinguished. Keep the underlying detector and reviewer fixed. Tune the gate on a development split by scenario and author. Compare English calibration, local calibration of the same gate, and a deterministic source and authority policy using the same trusted inputs.

**Baseline and headline metric.** Measure **authorized task completion at equal escalation rates**, subject to a prespecified minimum recall on labeled unauthorized proposals. If the proposed gate misses the safety floor, report both operating points instead of declaring a win. The team already saw 74/150 false positives in one loose-text Peruvian Spanish condition versus 5/150 English, and Spanish task completion fell from 14/16 to 4/16 with one detector. Structured transactions were flagged in both languages. The earlier recorded 0/288 successful attacks means those runs cannot support an estimated reduction in attack success. Use new held-out monitor cases with known outcomes. [Team pilot](../vault/resultados.md) · [AgentDojo](https://arxiv.org/abs/2406.13352) · [Detector distribution shift](https://arxiv.org/html/2610.03448v1) · [FinHarness](https://arxiv.org/html/2605.27333#S4.SS3)

**Demo and decision.** Show similar customer language accompanying different verified authorization states and a held-out legitimate task that the original gate interrupts. Show whether a simple policy can already recover the task. This is the fastest fallback because cases, task utility scoring, and a measured failure are available. Its novelty depends on the matched calibration comparison, since finance routing and provenance-aware escalation already exist. [SIEVE](https://arxiv.org/abs/2512.06716) · [Calibration and Deferral](https://arxiv.org/html/2610.20907v1)

### 3. Does a fixed deception monitor keep its operating point across native Spanish and code-switching?

**Setting and technique.** Use matched English and native Chilean Spanish status reports for one harmless mock workflow. Hold the underlying service outcome fixed across successful and failed operations. Include truthful reports, explicit uncertainty, and wrong reports after verifiable tool failures. Split by workflow template. Freeze one English-calibrated black-box monitor and compare it with the same monitor given an independently generated service receipt, under the same reviewer budget. Keep a deterministic receipt comparator as an inexpensive reference. FTA makes the reporting question and evidence-contract condition established prior art; the proposed slice tests external observation and native-register calibration with a success control, dimensions FTA explicitly leaves open. [FTA](https://arxiv.org/html/2609.35732v1#S5)

**Headline metric and demo.** Measure the **change in recall of state–report contradictions on Spanish at a frozen operating point**, with false alarms on honest and uncertain reports shown by language. Show one fluent report that disagrees with the service, then an honestly uncertain report it should leave alone. The outcome is a measurable contradiction. Inferring deliberate deception would require a different design. A white-box replication only makes sense if the team already has activation access and a dataset that adds a meaningful native-register or calibration test. [Cross-lingual deception probes](https://aclanthology.org/2026.mrl-1.33/) · [FTA](https://arxiv.org/html/2609.35732v1#S5) · [DecepEval](https://arxiv.org/html/2610.07967v1) · [The Harness Is the Model](https://arxiv.org/abs/2611.06116)

### 4. Does an audit threshold transfer when the agent sees evaluation framing?

**Setting and technique.** Run one benign sandbox workflow with matched task, tools, timing, and independent scoring. Randomize the presence of evaluation framing while keeping substantive task instructions constant. Use a frozen monitor threshold and compare text-only evidence with the same monitor given verified outcome metadata. Check that outcome classes occur in both arms before interpreting a recall comparison.

**Headline metric and demo.** Measure the **change in monitor false-alert rate across the two contexts at a frozen threshold**, with independent task outcomes and missed failures reported as guardrails. The strong qualitative example is a changed self-description or reporting style while the authorized task and observed state remain the same. This ranks fourth because existing evaluations cover recognition and behavior, and a framing-only manipulation may yield too few informative errors for a weekend study. Use it as a robustness check if the primary experiment finishes early. [EvalAwareBench](https://www.microsoft.com/en-us/research/publication/evalawarebench-a-benchmark-for-measuring-evaluation-awareness-in-frontier-language-models/) · [Eval–production comparison](https://openai.com/safety-alignment/eval-production-behavior-gap/)

## Keep, cut, and run the weekend

**Keep** independent state observations, replayable fixtures, run identifiers, redacted trace exports, and one small viewer for the decisive comparison. Reuse the proxy as a source of observations if needed. Its current request-linking implementation is a useful same-actor heuristic baseline, because it can link containment rules and proximate same-actor events; the experiment tests related sessions without assuming a shared observed actor. [Current related-request logic](../apps/sentinel/src/ultimo-paso/related.ts) · [Evidence runner](../ultimo-paso/scoreboard/pipeline_eval.py)

**Cut** additional CVEs, advisory enrichment, GitHub drafting, dashboards beyond the one necessary trace, and generic IP or signature defenses from the submission's critical path. Move the existing WAF A/B to an appendix. Show a measurement about what the monitor can learn from evidence an agent does not control. Apart's winning omission project made a specific failure type observable, and third-place ActionLens tested a concrete environment-aware intervention with a documented utility trade-off. Tranquera's Platanus project page shows direct local precedent for a policy-proxy demo. These are illustrative examples, and the published sprint placements do not establish a formula for winning. [Apart results](https://apartresearch.com/sprints/ai-control-hackathon-2026-03-20-to-2026-03-22) · [ActionLens](https://apartresearch.com/sprints/projects/actionlens-preexecution-environment-probing-for-agent-action-approval-xy22) · [Tranquera](https://hack.platan.us/26-ar/vote/tranquera)

**Commit to a checkpoint.** First two hours, freeze the task policy, positive and negative labels, and review budget. Run a small calibration pilot across distinct workflow families. Require real room between the per-session baseline and oracle grouping, and include benign activity with overlapping entities. If the gap is visible, run the matched evaluation on held-out families. If the gap is absent or is reproduced by a simple current-state rule, switch to #2. Second day, run a blinded error review and package the report with the command, seeds, timestamps, model identifiers, prompt hashes, redacted records, and per-condition counts. Report audits, monitor tokens and latency. A small, labeled sandbox can establish a mechanism without estimating real-world incident prevalence. [ControlArena introduction](https://control-arena.aisi.org.uk/intro-to-control.html)

## What could invalidate the result

- **The corpus gives the answer away.** Ground-truth group IDs, time bursts unique to positives, or one object touched only by incidents create a shortcut. Hide IDs from inputs, vary ordering, and give benign work similar overlap. If shuffled histories still win, the attribution to receipt-guided selection fails.
- **Trusted receipts are incomplete or misleading.** Trust their origin and timestamping, while checking authorization semantics independently. Test missing and delayed receipts. Label coverage when either occurs. Multiple unrelated sessions may share legitimate state.
- **Equal call count hides unequal costs.** Match context caps and deadlines, report tokens and elapsed time, and avoid claiming savings from benchmark routing ratios alone. A broadly useful cheap-filter cascade already appears in Anthropic's classifier work. [Anthropic classifiers](https://www.anthropic.com/research/next-generation-constitutional-classifiers) · [FinHarness cost accounting](https://arxiv.org/html/2605.27333#S4.SS3)
- **The strongest competitor is deterministic.** If a static check with the same available information ties, the experiment identifies where simple instrumentation is sufficient. If the team finds uplift only after seeing final state, describe it as retrospective detection. Both outcomes should change what the team builds.
